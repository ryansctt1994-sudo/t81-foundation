# tools/vscode-t81

VS Code extension assets for T81 language editing support.

## Files
- `package.json`: extension metadata/contributions
- `language-configuration.json`: language pairing/comments/brackets
- `syntaxes/t81.tmLanguage.json`: TextMate grammar

## Development
- Update grammar and language configuration together.
- Keep keyword/operator updates aligned with frontend parser/lexer behavior.
