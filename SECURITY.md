# Security Policy

## Supported Branch

Security fixes are published for the `main` branch.

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories for this repository.

If advisory reporting is unavailable, open a private issue with:
- affected component/path
- impact summary
- minimal reproduction
- suggested remediation (if known)

Do not disclose proof-of-concept exploit details in public issues before a fix is available.
