# T81 Architecture Overview

This document provides a high-level overview of the T81 system architecture.

## Core Components

1.  **TISC (Ternary Instruction Set Computer)**: The foundational instruction set architecture.
2.  **T81VM (Virtual Machine)**: The runtime environment for executing TISC code.
3.  **Axion Kernel**: The operating kernel managing resources and execution.
4.  **Hanoi VM**: The high-level virtual machine layer.
5.  **T81Lang**: The primary programming language for the T81 platform.

## Design Principles

*   **Ternary Logic**: Utilizing balanced ternary logic (-1, 0, 1) for efficiency and expressiveness.
*   **Determinism**: Ensuring reproducible execution across all platforms.
*   **Security**: Capabilities-based security model.
