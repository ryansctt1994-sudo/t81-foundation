# T81 Foundation Documentation

Welcome to the T81 Foundation documentation. This structure follows the **Diátaxis** framework, organizing documentation into four distinct quadrants to serve different user needs.

These are lessons that take the reader by the hand through a series of steps to complete a project of some kind.

- **[AI Quickstart](tutorials/ai-quickstart.md)**: Get started with AI models in T81.
- **[C++ Quickstart](tutorials/cpp-quickstart.md)**: A hands-on guide to building and running the core C++ codebase.
- **[Onboarding](tutorials/onboarding.md)**: General onboarding guide.
- **[User Manual](tutorials/user-manual.md)**: Detailed user manual.
