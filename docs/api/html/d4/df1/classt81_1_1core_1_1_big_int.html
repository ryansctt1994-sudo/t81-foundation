Detailed Description

Represents a canonical arbitrary-precision integer.

This class provides a foundational data type for handling integers that may exceed the limits of standard primitive types. It is used throughout the T81 ecosystem for both numerical calculations and data representation.

Note
This is a placeholder implementation. The full, specification-compliant BigInt is defined in spec/t81-data-types.md.
