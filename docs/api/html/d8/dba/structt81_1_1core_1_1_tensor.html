template<typename T>
struct t81::core::Tensor< T >

A multi-dimensional array (Tensor) container.

Template Parameters
TThe data type of the elements in the tensor.

This struct represents a tensor with a specific shape and underlying data. It is a foundational data structure for all numerical and symbolic computation in the T81 ecosystem.

Note
This is a minimal implementation. The full, specification-compliant tensor semantics are defined in spec/t81-data-types.md.
