Detailed Description

Defines the T81Agent class, a self-contained cognitive entity.

The T81Agent class encapsulates the components of a ternary-native agent, including its unique identity, belief state, memory, and an explicit entropy pool for thermodynamic accounting of operations.

This version keeps the high-level behavior but avoids copying T81Entropy and avoids unsupported arithmetic on T81Prob.
