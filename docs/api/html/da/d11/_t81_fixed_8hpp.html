Detailed Description

Balanced ternary fixed-point arithmetic on top of T81Int.

T81Fixed<IntegerTrits, FractionalTrits> is a thin semantic wrapper over T81Int<IntegerTrits + FractionalTrits>. All arithmetic is done in balanced ternary; scaling only appears at the double conversion boundary.
