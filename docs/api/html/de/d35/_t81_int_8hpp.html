Detailed Description

Balanced ternary integer with packed trits.

Features: • Packed 4 trits per byte (2 bits each: 0 = N, 1 = Z, 2 = P) • Correct balanced ternary arithmetic (+, -, *, /, %) • Trit proxy, operator[], tritwise shifts • Safe to_int64() with overflow checking • kMinValue / kMaxValue as inline static constants
