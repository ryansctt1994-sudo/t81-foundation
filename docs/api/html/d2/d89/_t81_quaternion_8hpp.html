Detailed Description

Defines the T81Quaternion class for 3D/4D geometry and rotations.

This file provides the T81Quaternion class, which represents a quaternion using balanced-ternary components. It is designed for exact and efficient 3D/4D geometry, supporting operations such as the Hamilton product, conjugation, normalization, and spherical linear interpolation (slerp). It is also used in cognitive models for representing "intent rotation."
