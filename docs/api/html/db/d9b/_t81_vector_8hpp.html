Detailed Description

Defines the T81Vector class, a mathematical vector with physical semantics.

This file provides the T81Vector<N, Scalar> class, a fixed-size N-dimensional vector designed as a geometric object rather than a general-purpose container. It supports a rich set of constexpr-friendly mathematical and geometric operations, including dot and cross products, normalization, and rotations via T81Quaternion.
