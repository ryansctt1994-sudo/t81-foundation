# legacy

Deprecated or historical implementations preserved for reference.

## Contents
- `hanoivm/`: An older Rust-based implementation of the HanoiVM, built with Bazel. This codebase serves as a reference for the original design and behavior but is no longer actively maintained or built in the current CI pipeline.

## Status
Code in this directory is **not** part of the canonical T81 runtime and is not guaranteed to compile or run with modern tools.
