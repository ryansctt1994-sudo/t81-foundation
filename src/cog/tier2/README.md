# `src/cog/tier2` (T729)

Directory documentation for `src/cog/tier2`.

## Purpose
This module implements Tier 2 of the Cognitive Framework, corresponding to T729 (AGI-Recursive Cognition).

## Key Components
- `ReflectiveFrame`: Captures reasoning state and justification chains.
- `JustificationChain`: Tracks the steps leading to a cognitive conclusion.

## Responsibilities
- Provide mechanisms for introspection and self-explanation.
- Ensure all cognitive actions are accompanied by justification metadata.

## Expectations
- Reasoning processes should be transparent and auditable.
- Justification chains must be preserved across operations.
