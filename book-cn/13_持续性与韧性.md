# 第 13 章：持续性与韧性

## 13.1 无尘室协议

**状态：已记录**

**无尘室重建协议** 定义了在假设基础设施完全丧失的情况下，从头开始重建 T81 系统所需的最少步骤集。

### 13.1.1 最小引导
1.  **源代码**：`src/` 和 `include/` 目录的副本。
2.  **编译器**：任何符合 C++23 标准的编译器（Clang 18+, GCC 14+）。
3.  **构建系统**：CMake 3.25+。

**命令**：
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

### 13.1.2 验证
重建后，系统必须针对一组已知的 `CanonHash81` 工件验证自身。
```bash
./build/t81 repro-hash tests/fixtures/t81lang_determinism
```

## 13.2 长期归档

**状态：愿景**

T81 的目标是在 50 年后仍可读且可执行。
*   **格式稳定性**：`.t81` 源代码和 `.tisc` 字节码格式已被冻结。
*   **依赖项**：核心 VM 除了标准 C++ 库之外，没有外部运行时依赖项。
