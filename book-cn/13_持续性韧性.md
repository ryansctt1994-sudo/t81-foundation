# 第 13 章：持续性与韧性 (Continuity and Resilience)

## 13.1 洁净室协议 (The Cleanroom Protocol)

**状态：已记录**

**洁净室重建协议**定义了在假设基础设施完全丢失的情况下，从零开始重建 T81 系统所需的最少步骤。

### 13.1.1 最小化引导 (Minimal Bootstrap)

1. **源代码**：`src/` 和 `include/` 目录的副本。
2. **编译器**：任何符合 C++23 标准的编译器（Clang 18+，GCC 14+）。
3. **构建系统**：CMake 3.25+。

**构建命令**：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

```

### 13.1.2 验证

重建完成后，系统必须针对一组已知的 `CanonHash81` 构件进行自我验证。

```bash
./build/t81 repro-hash tests/fixtures/t81lang_determinism

```

## 13.2 长期存档

**状态：规划中**

T81 的目标是确保在 50 年以后仍能被读取和执行。

* **格式稳定性**：`.t81` 源码和 `.tisc` 字节码格式已被冻结。
* **依赖项**：核心虚拟机除了标准 C++ 库之外，没有任何外部运行时依赖。
