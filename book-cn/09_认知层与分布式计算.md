# 第 9 章：认知层与分布式计算

## 9.1 认知层模型

**状态：已实现**

T81 将计算复杂度组织成一个 **认知层 (Cognitive Tiers)** 的层级结构。这允许 Axion 内核在执行之前推断程序的 *意图* 和 *能力*。

| 层级 | 名称 | 能力 | 递归限制 |
| :--- | :--- | :--- | :--- |
| **0** | **基础 (Base)** | 基本算术 (`Add`, `Sub`)，线性流。 | 0 |
| **1** | **符号 (Symbolic)** | 张量操作，基本循环。 | 81 |
| **2** | **反射 (Reflective)** | `MetaRead`, `MetaReflect`。 | 243 |
| **3** | **递归 (Recursive)** | 自修改，证明生成。 | 1024 (策略) |
| **4** | **分布式 (Distributed)** | Gossip，状态合并。 | N/A |
| **5** | **无限 (Infinite)** | 几何级数，非终止形式。 | N/A |

> **实现**：层级逻辑在 `src/cog/tier[1-5]/` 中模块化。

## 9.2 分布式计算 (第 4 层)

**状态：已实现并测试**

**分布式层** 使多个 T81VM 实例能够作为一致的群体运行。

### 9.2.1 Gossip 协议
节点通过使用 `Gossip` 和 `Merge` 操作码的确定性 Gossip 协议交换状态更新。
*   **消息格式**：`(Tag, Payload, LamportTick, NodeID)`。
*   **合并策略**：基于 `TickSync` 时间戳的类 CRDT 合并。
*   **确定性**：给定相同的消息到达序列，所有节点上的最终合并状态都是相同的。

> **参考**：`src/cog/tier4/distributed.cpp` 和 `tests/cpp/test_tier4_distributed.cpp`。

### 9.2.2 逻辑时钟 (TickSync)
VM 维护一个 Lamport 逻辑时钟 (`R75`)。
*   **内部 Tick**：每条指令递增。
*   **同步**：收到消息时更新：`Tick = max(LocalTick, RemoteTick) + 1`。
*   **一致性**：`Coherence` 操作码返回本地和全局 tick 之间的漂移。

## 9.3 无限形式 (第 5 层)

**状态：已实现并测试**

第 5 层引入了“无限”数据结构，例如几何级数。
*   **表示**：有限生成器 `(a, r)` 表示级数 $a + ar + ar^2 + \dots$。
*   **操作**：`InfExpand` 计算第 $N$ 项。`InfConverge` 检查是否 $|r| < 1$。
*   **签名**：`InfSignature` 生成 *生成函数* 的唯一哈希，而不是无限数据。

> **参考**：`src/cog/tier5/infinite.cpp` 和 `tests/cpp/test_infinite_opcodes.cpp`。
