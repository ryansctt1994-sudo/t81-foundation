# 第 7 章：验证与审计

## 7.1 验证技术栈 (The Verification Stack)

**状态：已实现**

T81 提供了一套全面的验证工具，以确保技术栈每一层级的正确性。

1. **单元测试 (Unit Tests)**：位于 `tests/cpp/` 的底层 C++ 测试。
2. **集成测试 (Integration Tests)**：位于 `tests/fixtures/` 的端到端 T81Lang 程序。
3. **属性测试 (Property Tests)**：针对算术不变性的随机化属性测试（`tests/cpp/test_property_invariants.cpp`）。
4. **确定性网关 (Determinism Gate)**：CI 脚本 `scripts/ci/t81lang_repro_gate.py`，用于强制执行位级精确的可重现性。

## 7.2 确定性网关

**状态：已实现并激活**

`t81lang_repro_gate.py` 脚本是衡量构建正确性的主要准则。其流程如下：

1. 编译标准测试套件（`tests/fixtures/t81lang_determinism`）。
2. 计算生成的 TISC 字节码的 SHA-256 哈希值。
3. 将这些哈希值与规范清单 (`repro.json`) 进行对比。

如果任何哈希值不一致，构建将失败。这确保了编译器的更改不会无意中改变代码生成。

## 7.3 追踪验证 (Trace Verification)

**状态：已实现**

Axion 追踪允许对执行过程进行事后验证。

* **回放 (Replay)**：`t81 trace replay program.tisc trace.txt` 重新执行程序，并验证记录的追踪日志是否与实时执行完全匹配。
* **差异比对 (Diff)**：`t81 trace diff trace_a.txt trace_b.txt` 突出显示两次运行之间的差异点。

> **验证**：`tests/cpp/axion_log_determinism_test.cpp` 确保了追踪日志的完整性。
