# 第 7 章：验证与审计

## 7.1 验证栈

**状态：已实现**

T81 提供了一套全面的验证工具，以确保栈的每一层都正确。

1.  **单元测试**：`tests/cpp/` 中的低级 C++ 测试。
2.  **集成测试**：`tests/fixtures/` 中的端到端 T81Lang 程序。
3.  **属性测试**：算术不变性的随机化基于属性的测试 (`tests/cpp/test_property_invariants.cpp`)。
4.  **确定性网关**：强制执行位精确可重现性的 CI 脚本 `scripts/ci/t81lang_repro_gate.py`。

## 7.2 确定性网关

**状态：已实现并激活**

`t81lang_repro_gate.py` 脚本是构建正确性的主要仲裁者。它：
1.  编译标准测试套件 (`tests/fixtures/t81lang_determinism`)。
2.  计算生成的 TISC 字节码的 SHA-256 哈希值。
3.  将这些哈希值与规范清单 (`repro.json`) 进行比较。

如果任何哈希值不同，构建就会失败。这确保了编译器更改不会无意中改变代码生成。

## 7.3 追踪验证

**状态：已实现**

Axion 追踪允许对执行进行事后验证。
*   **重放**：`t81 trace replay program.tisc trace.txt` 重新执行程序并验证记录的追踪与实时执行是否匹配。
*   **差异**：`t81 trace diff trace_a.txt trace_b.txt` 高亮显示两次运行之间的差异。

> **验证**：`tests/cpp/axion_log_determinism_test.cpp` 确保追踪完整性。
