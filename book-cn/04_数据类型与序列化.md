# 第 4 章：数据类型与序列化

## 4.1 原生类型

**状态：已实现并测试**

T81 架构建立在平衡三进制原语的基础之上。这些类型的即被设计为可以在二进制硬件上高效模拟，同时保持 base-3 逻辑的数学属性。

### 4.1.1 Trits 和 Trytes
*   **Trit**：信息的基本原子，取值为 $\{-1, 0, 1\}$。
*   **Tryte**：一系列 trits。标准 tryte 宽度为 4 trits（$3^4 = 81$ 个值），通常打包进 `uint8_t` 进行存储。

> **实现**：`include/t81/ternary.hpp` 定义了 `Trit` 枚举和转换逻辑。

### 4.1.2 T81Int (任意精度整数)
`T81Int` 是一种使用打包平衡三进制表示的可变宽度整数类型。
*   **存储**：每 trit 2 位。
*   **范围**：关于零对称（$-\frac{3^N-1}{2} \dots +\frac{3^N-1}{2}$）。
*   **规范化**：在规范序列化形式中严格禁止前导零。零值由单个零 trit 表示。

> **验证**：`tests/cpp/test_t81int.cpp` 和 `tests/cpp/test_property_invariants.cpp`。

## 4.2 T81Float 和 dmath

**状态：已实现 (核心) / 部分 (扩展)**

浮点算术是跨平台计算中非确定性的主要来源（由于 FMA 融合、超越函数精度等方面的 IEEE-754 差异）。T81 通过 `T81Float` 解决了这个问题。

### 4.2.1 规范定义
一个 `T81Float` 是一个元组 $(m, e)$，表示值 $m \times 3^e$。
*   $m$：尾数 (T81Int)。
*   $e$：指数 (T81Int)。
*   **不变性**：尾数 $m$ 必须被规范化，使其最高有效 trit 不为零，除非该值正好为零。

### 4.2.2 dmath 后端
为了实现 **严格确定性**，VM 采用了 `dmath`（确定性数学），这是一个软件定义的算术库。
*   **核心操作**：`Add`, `Sub`, `Mul` 是精确且确定性的（在 `T81Float.hpp` 中实现）。
*   **超越函数**：`Sin`, `Cos`, `Tan`, `Exp`, `Log`, `Sqrt` 使用 `dmath` 计算（具有固定迭代次数的泰勒级数），保证在任何架构上都有位精确的结果。
*   **扩展函数**：`Asin`, `Acos`, `Sinh`, `Pow` 目前依赖于宿主 `double` 精度（除非定义了 `T81_DETERMINISTIC`，在这种情况下它们可能会返回 `NaE` 或使用慢速软件模拟）。

> **验证**：`tests/cpp/test_T81Float.cpp` 验证了特殊值和超越函数的正确性。`include/t81/core/detail/dmath.hpp` 包含实现。

## 4.3 张量与规范布局

**状态：已实现并测试**

张量 (`T729Tensor`, `T81Tensor`) 是认知层的主力。

### 4.3.1 内存布局
张量以 **行主序 (Row-Major)** 存储。
*   **形状**：维度向量 $(d_0, d_1, \dots, d_n)$。
*   **步幅**：计算公式为 $s_i = \prod_{j=i+1}^n d_j$。
*   **对齐**：张量数据在 `Tensor` 内存段中对齐到 64 字节边界。

### 4.3.2 序列化 (.t81w)
`.t81w` (T81 Weights) 格式是用于持久化张量模型的标准容器。版本 2 (`T81W2`) 支持量化和规范哈希。

**二进制结构**：
1.  **魔数头**：`0x54383157` ("T81W")。
2.  **版本**：`0x02`。
3.  **目录**：`(Hash, Offset, Length)` 元组列表。
4.  **Blob 数据**：连续的张量数据。

**量化格式**：
*   **F32**：标准 IEEE-754 浮点数（已规范化）。
*   **T3_K**：带有块级缩放的每 trit 2 位打包。

> **来源**：`include/t81/weights.hpp` 和 `include/t81/tensor.hpp`。

## 4.4 规范序列化规则

**状态：已实现**

为了确保一致的哈希 (`CanonRef`)，所有数据在序列化之前必须被规范化。

1.  **BigInt**：去除前导零。零为 `[0]`。
2.  **分数**：
    *   化简为最简分数：$\gcd(num, den) = 1$。
    *   分母必须为正。
    *   零为 $0/1$。
3.  **浮点数**：
    *   标准化尾数/指数。
    *   NaN 载荷被清零。
    *   负零被规范化为正零。
4.  **映射/字典**：
    *   Keys 必须按其规范二进制表示的字典顺序排序。
5.  **图**：
    *   节点按拓扑排序顺序重新索引，以确保存图同构产生相同的字节流。

> **验证**：`tests/cpp/test_property_invariants.cpp` 通过基于属性的测试验证这些规范化属性。
