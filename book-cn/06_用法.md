# 第 6 章：用法与命令行界面 (CLI)

## 6.1 统一命令行界面

**状态：已实现并已测试**

`t81` 可执行文件为所有操作提供了一个统一的接口。

### 6.1.1 基础命令

* **`compile`**：将 T81Lang 源码 (`.t81`) 编译为 TISC 字节码 (`.tisc`)。
```bash
t81 compile examples/hello_world.t81 -o hello.tisc

```


* **`run`**：在虚拟机上执行 TISC 字节码。
```bash
t81 run hello.tisc

```


* **`check`**：执行语法和语义分析而不生成代码。
```bash
t81 check examples/hello_world.t81

```



### 6.1.2 调试与检查

* **`disasm`**：将 TISC 字节码反汇编为可读的助记符。
```bash
t81 disasm hello.tisc

```


* **`debug`**：启动交互式调试器（支持单步执行、检查寄存器）。
```bash
t81 debug hello.tisc

```


* **`trace`**：管理 Axion 审计追踪日志。
```bash
t81 trace show trace.txt
t81 trace diff trace_a.txt trace_b.txt
t81 trace replay hello.tisc trace.txt

```



### 6.1.3 模型管理

* **`weights`**：用于导入和量化神经网络权重的工具。
```bash
t81 weights import model.safetensors -o model.t81w
t81 weights info model.t81w
t81 weights quantize model.safetensors --to-gguf model.gguf

```


* **`canonize-tensor`**：验证并规范化张量文件。
```bash
t81 canonize-tensor model.t81w

```


* **`repro-hash`**：计算目录的规范哈希值以供验证。
```bash
t81 repro-hash tests/fixtures/t81lang_determinism

```



> **验证**：运行 `build/t81 --help` 查看当前精确的用法说明。
