# 第 5 章：安装与构建

## 5.1 前提条件

若要从源代码构建 T81（进行洁净室重建），您需要准备以下环境：

* **C++ 编译器**：Clang 18+ 或 GCC 14+（必须支持 C++23 标准）。
* **构建系统**：CMake 3.25+。
* **Python**：Python 3.10+（用于运行验证脚本）。

## 5.2 构建步骤

1. **克隆仓库**：
```bash
git clone https://github.com/t81dev/t81-foundation.git
cd t81-foundation

```


2. **配置与构建**：
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

```


3. **验证构建**：
运行确定性网关脚本，以确保您的工具链产生的二进制文件与参考哈希值在位级上完全一致。
```bash
python3 scripts/ci/t81lang_repro_gate.py --t81-bin build/t81 --check

```



---

## 5.3 确定性网关 (Determinism Gate)

`repro_gate.py` 脚本是衡量构建正确性的主要准则。它会编译一套参考程序（位于 `tests/fixtures/t81lang_determinism`），并将生成的 TISC 字节码哈希值与已知正确的 `repro.json` 清单进行对比。

> **源码位置**：`scripts/ci/t81lang_repro_gate.py`。
