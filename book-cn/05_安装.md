# 第 5 章：安装与构建

## 5.1 前置条件

要从源代码构建 T81（无尘室重建），您需要：
*   **C++ 编译器**：Clang 18+ 或 GCC 14+（需要 C++23 支持）。
*   **构建系统**：CMake 3.25+。
*   **Python**：Python 3.10+（用于验证脚本）。

## 5.2 构建步骤

1.  **克隆仓库**：
    ```bash
    git clone https://github.com/t81dev/t81-foundation.git
    cd t81-foundation
    ```

2.  **配置并构建**：
    ```bash
    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --parallel
    ```

3.  **验证构建**：
    运行确定性网关脚本，以确保您的工具链产生相对于参考哈希位精确的二进制文件。
    ```bash
    python3 scripts/ci/t81lang_repro_gate.py --t81-bin build/t81 --check
    ```

## 5.3 确定性网关

`repro_gate.py` 脚本是构建正确性的主要仲裁者。它编译一套参考程序 (`tests/fixtures/t81lang_determinism`) 并将生成的 TISC 字节码哈希与已知的 `repro.json` 清单进行比较。

> **来源**：`scripts/ci/t81lang_repro_gate.py`。
