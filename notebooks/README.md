# notebooks

Interactive Jupyter notebooks for exploring T81 concepts, tutorials, and data analysis.

## Contents
- `00_t81_orientation.ipynb`: An introduction to the T81 ecosystem and its core philosophy.
- `01_balanced_ternary_playground.ipynb`: A hands-on environment for experimenting with balanced ternary arithmetic and logic.
- `02_t81vm_trace_walkthrough.ipynb`: A guided tour through HanoiVM execution traces, demonstrating how instructions are processed and states transition.

## Usage
To run these notebooks, ensure you have Jupyter installed and the necessary Python dependencies (including the `t81` Python bindings if required).
