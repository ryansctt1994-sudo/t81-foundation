# Глава 6: Использование и CLI

## 6.1 Единый интерфейс командной строки (CLI)

**Статус: Реализовано и протестировано**

Исполняемый файл `t81` предоставляет единый интерфейс для всех операций.

### 6.1.1 Основные команды

*   **`compile`**: Компилирует исходный код T81Lang (`.t81`) в байткод TISC (`.tisc`).
    ```bash
    t81 compile examples/hello_world.t81 -o hello.tisc
    ```

*   **`run`**: Выполняет байткод TISC на виртуальной машине.
    ```bash
    t81 run hello.tisc
    ```

*   **`check`**: Выполняет синтаксический и семантический анализ без генерации кода.
    ```bash
    t81 check examples/hello_world.t81
    ```

### 6.1.2 Отладка и инспекция

*   **`disasm`**: Дизассемблирует байткод TISC в читаемые мнемоники.
    ```bash
    t81 disasm hello.tisc
    ```

*   **`debug`**: Запускает интерактивный отладчик (пошаговое выполнение, инспекция регистров).
    ```bash
    t81 debug hello.tisc
    ```

*   **`trace`**: Управляет журналами аудита Axion.
    ```bash
    t81 trace show trace.txt
    t81 trace diff trace_a.txt trace_b.txt
    t81 trace replay hello.tisc trace.txt
    ```

### 6.1.3 Управление моделями

*   **`weights`**: Инструменты для импорта и квантования весов нейронных сетей.
    ```bash
    t81 weights import model.safetensors -o model.t81w
    t81 weights info model.t81w
    t81 weights quantize model.safetensors --to-gguf model.gguf
    ```

*   **`canonize-tensor`**: Проверяет и нормализует файл тензора.
    ```bash
    t81 canonize-tensor model.t81w
    ```

*   **`repro-hash`**: Вычисляет канонический хэш директории для верификации.
    ```bash
    t81 repro-hash tests/fixtures/t81lang_determinism
    ```

> **Верификация**: Запустите `build/t81 --help` для просмотра актуальной справки.
