# Глава 13: Непрерывность и устойчивость

## 13.1 Протокол "чистой комнаты"

**Статус: Документировано**

**Протокол реконструкции в "чистой комнате"** определяет минимальный набор шагов, необходимых для пересборки системы T81 с нуля, предполагая полную потерю инфраструктуры.

### 13.1.1 Минимальный начальный запуск
1.  **Исходный код**: Копия директорий `src/` и `include/`.
2.  **Компилятор**: Любой компилятор, совместимый с C++23 (Clang 18+, GCC 14+).
3.  **Система сборки**: CMake 3.25+.

**Команда**:
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

### 13.1.2 Верификация
После пересборки система должна верифицировать себя относительно известного набора артефактов `CanonHash81`.
```bash
./build/t81 repro-hash tests/fixtures/t81lang_determinism
```

## 13.2 Долгосрочное архивирование

**Статус: Желаемое**

Цель T81 — быть читаемым и исполняемым через 50+ лет.
*   **Стабильность формата**: Форматы исходного кода `.t81` и байткода `.tisc` заморожены.
*   **Зависимости**: Базовая VM не имеет никаких внешних рантайм-зависимостей, кроме стандартной библиотеки C++.
