# Глава 4: Типы данных и сериализация

## 4.1 Примитивные типы

**Статус: Реализовано и протестировано**

Архитектура T81 построена на фундаменте сбалансированных троичных примитивов. Эти типы спроектированы для эффективной эмуляции на двоичном оборудовании при сохранении математических свойств логики по основанию 3.

### 4.1.1 Триты и трайты
*   **Трит**: Фундаментальный атом информации, принимающий значения $\{-1, 0, 1\}$.
*   **Трайт**: Последовательность тритов. Стандартная ширина трайта составляет 4 трита ($3^4 = 81$ значений), часто упаковывается в `uint8_t` для хранения.

> **Реализация**: `include/t81/ternary.hpp` определяет перечисление `Trit` и логику преобразования.

### 4.1.2 T81Int (Целое число произвольной точности)
`T81Int` — это целочисленный тип переменной ширины, использующий упакованное сбалансированное троичное представление.
*   **Хранение**: 2 бита на трит.
*   **Диапазон**: Симметричный относительно нуля ($-\frac{3^N-1}{2} \dots +\frac{3^N-1}{2}$).
*   **Нормализация**: Ведущие нули строго запрещены в канонической сериализованной форме. Значение ноль представляется одним нулевым тритом.

> **Верификация**: `tests/cpp/test_t81int.cpp` и `tests/cpp/test_property_invariants.cpp`.

## 4.2 T81Float и dmath

**Статус: Реализовано (Ядро) / Частично (Расширенное)**

Арифметика с плавающей запятой является основным источником недетерминизма в кросс-платформенных вычислениях (из-за различий IEEE-754 в слиянии FMA, трансцендентной точности и т.д.). T81 решает эту проблему с помощью `T81Float`.

### 4.2.1 Каноническое определение
`T81Float` — это кортеж $(m, e)$, представляющий значение $m \times 3^e$.
*   $m$: Мантисса (T81Int).
*   $e$: Экспонента (T81Int).
*   **Инвариант**: Мантисса $m$ должна быть нормализована так, чтобы ее самый старший трит был ненулевым, если только значение не является ровно нулем.

### 4.2.2 Бэкенд dmath
Для достижения **Строгого детерминизма** VM использует `dmath` (Детерминированная математика), программно-определяемую арифметическую библиотеку.
*   **Основные операции**: `Add`, `Sub`, `Mul` точны и детерминированы (реализованы в `T81Float.hpp`).
*   **Трансцендентные функции**: `Sin`, `Cos`, `Tan`, `Exp`, `Log`, `Sqrt` вычисляются с использованием `dmath` (ряды Тейлора с фиксированным числом итераций), гарантируя побитово точные результаты на любой архитектуре.
*   **Расширенные функции**: `Asin`, `Acos`, `Sinh`, `Pow` в настоящее время полагаются на точность хоста `double` (если не определен `T81_DETERMINISTIC`, в противном случае они могут вернуть `NaE` или использовать медленную программную эмуляцию).

> **Верификация**: `tests/cpp/test_T81Float.cpp` проверяет корректность специальных значений и трансцендентных функций. `include/t81/core/detail/dmath.hpp` содержит реализацию.

## 4.3 Тензоры и канонические макеты

**Статус: Реализовано и протестировано**

Тензоры (`T729Tensor`, `T81Tensor`) — это "рабочие лошадки" когнитивных уровней.

### 4.3.1 Схема памяти
Тензоры хранятся в порядке **Row-Major** (по строкам).
*   **Форма**: Вектор размерностей $(d_0, d_1, \dots, d_n)$.
*   **Шаг (Stride)**: Вычисляется как $s_i = \prod_{j=i+1}^n d_j$.
*   **Выравнивание**: Данные тензора выровнены по границам 64 байта в сегменте памяти `Tensor`.

### 4.3.2 Сериализация (.t81w)
Формат `.t81w` (T81 Weights) — это стандартный контейнер для сохранения тензорных моделей. Версия 2 (`T81W2`) поддерживает квантование и каноническое хэширование.

**Бинарная структура**:
1.  **Магический заголовок**: `0x54383157` ("T81W").
2.  **Версия**: `0x02`.
3.  **Оглавление**: Список кортежей `(Hash, Offset, Length)`.
4.  **Данные BLOB**: Непрерывные данные тензоров.

**Форматы квантования**:
*   **F32**: Стандартный IEEE-754 float (канонизированный).
*   **T3_K**: Упаковка 2-бита-на-трит с блочным масштабированием.

> **Источник**: `include/t81/weights.hpp` и `include/t81/tensor.hpp`.

## 4.4 Правила канонической сериализации

**Статус: Реализовано**

Для обеспечения согласованного хэширования (`CanonRef`) все данные должны быть нормализованы перед сериализацией.

1.  **BigInt**: Удалить ведущие нули. Ноль — это `[0]`.
2.  **Fraction**:
    *   Сократить до несократимой дроби: $\gcd(num, den) = 1$.
    *   Знаменатель должен быть положительным.
    *   Ноль — это $0/1$.
3.  **Float**:
    *   Стандартизировать мантиссу/экспоненту.
    *   Нагрузка NaN обнуляется.
    *   Отрицательный ноль нормализуется в положительный ноль.
4.  **Map/Dictionary**:
    *   Ключи должны быть отсортированы лексикографически по их каноническому двоичному представлению.
5.  **Graph**:
    *   Узлы переиндексируются в порядке топологической сортировки, чтобы изоморфизм графов давал идентичные потоки байтов.

> **Верификация**: `tests/cpp/test_property_invariants.cpp` проверяет эти свойства нормализации с помощью тестирования на основе свойств.
