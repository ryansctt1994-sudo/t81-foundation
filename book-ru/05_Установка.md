# Глава 5: Установка и сборка

## 5.1 Требования

Чтобы собрать T81 из исходного кода (реконструкция в "чистой комнате"), вам понадобятся:
*   **Компилятор C++**: Clang 18+ или GCC 14+ (требуется поддержка C++23).
*   **Система сборки**: CMake 3.25+.
*   **Python**: Python 3.10+ (для скриптов валидации).

## 5.2 Процедура сборки

1.  **Клонирование репозитория**:
    ```bash
    git clone https://github.com/t81dev/t81-foundation.git
    cd t81-foundation
    ```

2.  **Конфигурация и сборка**:
    ```bash
    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --parallel
    ```

3.  **Верификация сборки**:
    Запустите скрипт гейта детерминизма, чтобы убедиться, что ваш инструментарий производит побитово точные бинарные файлы относительно эталонных хэшей.
    ```bash
    python3 scripts/ci/t81lang_repro_gate.py --t81-bin build/t81 --check
    ```

## 5.3 Гейт детерминизма

Скрипт `repro_gate.py` является главным арбитром корректности сборки. Он компилирует набор эталонных программ (`tests/fixtures/t81lang_determinism`) и сравнивает полученные хэши байткода TISC с известным хорошим манифестом `repro.json`.

> **Источник**: `scripts/ci/t81lang_repro_gate.py`.
